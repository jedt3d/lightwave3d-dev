# Architecture
Static HTML, CSS, and vanilla JavaScript. No build step; project-relative URLs; hash routing. `assets/course.js` stores original lesson content and references. `assets/app.js` renders course, labs, library, progress. `assets/tokens.css` holds Figma-compatible semantic theme variables. `examples/` holds original educational LScript snippets. Browser progress/theme use localStorage (local to this browser, not synced). SVG Vector Lab draws an explicitly labeled XY projection and computes full 3D vector magnitude.
Separate geometry algorithms from host API calls in later exercises. Record host version, script type, selection, expected output, observed output, errors and screenshot when testing LScript. Python migration later. Never claim sample scripts are tested in LW 2026 until tested inside that host.
