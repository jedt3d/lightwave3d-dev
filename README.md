# LightWave 3D Dev

A Thai portal for LW3D developer.

## LightWave Developer Workbench
หลักสูตร 3D Computer Graphics ผ่าน LScript และ Legacy Plugin Study ก่อนต่อยอดไป Python 3. เป็น independent educational project ไม่ได้เป็นเว็บไซต์อย่างเป็นทางการของ LightWave.

Local preview: run `python3 -m http.server 8000` in this repository; open http://localhost:8000/.
GitHub Pages target: https://jedt3d.github.io/lightwave3d-dev/ (deployment must be verified).

Initial lessons are based on documented legacy LScript APIs, not tested in LightWave 2026. See compatibility notes.
